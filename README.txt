FUNDAMENTOS DE JAVASCRIPT - MODULO 6
====================================

Descripcion
-----------
Laboratorio de practica de JavaScript. Un archivo HTML enlaza un archivo
JavaScript externo (script.js) y una hoja de estilos (styles.css). Los
resultados se ven en la pagina y en la consola del navegador.

Archivos
--------
index.html Estructura HTML5 con etiquetas semanticas y comentarios.
styles.css Estilos de la pagina.
script.js Codigo JavaScript dividido en 4 secciones.
imagenes/logo.svg Imagen usada en el encabezado.
README.txt Este archivo.

Contenido de script.js
----------------------
1. Conceptos basicos: variables (var, let, const), tipos de datos, arreglos y objetos.
2. Control y funciones: if / else if / else, for, while, do...while y funciones.
3. Alcance y clausuras: diferencias entre var, let y const, y un contador con clausura.
4. Pruebas: campo de calificacion y botones para probar con distintos valores.

Como ejecutarlo
---------------
Abrir index.html en un navegador y abrir la consola (Ctrl + Shift + I).

Herramientas usadas
-------------------
Visual Studio Code, navegador Microsoft Edge, Git y GitHub.
